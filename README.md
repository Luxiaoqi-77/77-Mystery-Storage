# 沈小回

一个 Windows 桌面宠物。下载后直接运行，不需要安装。

## 下载

请到 GitHub Releases 下载最新版 `沈小回.exe`，双击运行即可。

## 功能

- 桌面待机、走路、睡觉、坐下、视线跟随、窗口边缘躲藏、窗口吸附等状态及互动。
- 拖到屏幕边缘可手动保持peek，再手动拖出解除。
- 右键桌宠可用横条调整大小。

## 开发构建

```powershell
npm install
npm run build
```

构建后的便携版会生成到：

```text
dist/沈小回.exe
```
