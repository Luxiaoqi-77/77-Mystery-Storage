# 桌宠

第一版功能：

- 常驻桌面、透明背景、置顶显示
- 鼠标拖拽移动
- 单击开心，连续快速点击生气
- 待机轻微呼吸
- 自动眨眼，眼神追随鼠标
- 鼠标长时间不动时会左右看
- 鼠标移动频率过高时坐下，过高后睡觉
- 贴近屏幕边缘时会小范围走动
- 长时间不互动会躲到屏幕边缘，鼠标移动可召回
- 右键菜单：召回、睡觉、坐下、开机自启、置顶、退出

## 运行

```powershell
npm install
npm run start
```
