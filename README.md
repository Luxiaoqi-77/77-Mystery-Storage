# 沈小回

一个 Windows 桌面宠物。下载后直接运行，不需要安装。

## 直接下载

在仓库里打开：

```text
dist/沈小回.exe
```

下载这个文件后双击运行即可。

## 功能

- 桌面待机、走路、睡觉、坐下、peek、窗口吸附等状态。
- 拖到屏幕边缘可手动保持 peek，再手动拖出解除。
- 右键桌宠可用横条调整大小。
- 仅显示在右下角系统托盘，不显示在任务栏。

## 开发构建

```powershell
npm install
npm run electron:build
```

构建后的便携版会生成到：

```text
dist/沈小回.exe
```
